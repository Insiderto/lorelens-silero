# lorelens-silero

Русский нейросетевой голос [Silero](https://github.com/snakers4/silero-models) для LoreLens:
читает записки вслух на этом компьютере, без ключа, интернета и оплаты. Сам ставит ударения и
различает омографы. Читает только по-русски.

*English: a Russian-only offline voice for LoreLens. It reads Russian text and nothing else. If
LoreLens speaks English for you, use the Supertonic voice from its settings instead.*

## Установка

Нужны Windows 10 или 11 (64 бита) и около 500 МБ на диске.

1. Скачайте архив `lorelens-silero-win-x64.zip` (около 200 МБ) со страницы
   [Releases](https://github.com/Insiderto/lorelens-silero/releases/latest).
2. Откройте папку голоса. Её путь написан в LoreLens: **Настройки › Озвучка › На этом
   компьютере › Silero**. Обычно это `%APPDATA%\LoreLens\voices\silero`: вставьте эту строку в
   адресную строку Проводника. Если папки `voices\silero` ещё нет, создайте её.
3. Распакуйте архив прямо в эту папку. Файлы (`silero_voice.dll`, `torch_cpu.dll`, `tts.jit` и
   остальные) должны лежать в самой `silero`, не во вложенной папке.
4. В LoreLens нажмите **«Проверить»** в том же блоке настроек. Появится список из пяти голосов:
   три женских и два мужских. Кнопка ▶ у голоса даёт его послушать.

Первое чтение после запуска LoreLens начинается на несколько секунд позже: загружается модель.

### Если не получилось

- **«Голос не установлен» после «Проверить».** Файлы лежат не там. Чаще всего архив распаковался
  во вложенную папку (`silero\lorelens-silero-win-x64\…`): перенесите файлы на уровень выше.
- **«Библиотека Silero не загрузилась».** В папке не хватает файлов. Их должно быть двенадцать,
  все из архива: распакуйте его заново целиком.
- **Голос молчит на английском тексте.** Так и должно быть: Silero знает только русские буквы.
  Латиница и числа перед чтением переводятся в русские слова приблизительно.
- Что именно пошло не так, записано в `lorelens.log`: в LoreLens рядом с ошибкой есть
  «Показать лог».

### Удалить

Удалите папку `voices\silero` и выберите в настройках LoreLens другой голос.

## Что в архиве

- `silero_voice.dll`: код из этого репозитория;
- библиотеки [libtorch](https://pytorch.org/) (CPU): `torch_cpu.dll`, `c10.dll`, `torch.dll`,
  `torch_global_deps.dll`, `libiomp5md.dll`, `libiompstubs5md.dll`, `uv.dll`;
- модель Silero TTS v5 (`v5_5_ru`) в виде, который читается без Python: `tts.jit`,
  `accentor.jit`, `homosolver.jit`, `data.json`.

## Как это устроено

Три нейросети модели запускаются через libtorch как есть, а обвязка, которая у Silero написана на
Python (очистка текста, ударения, омографы, токенизатор, типы вопросов), переписана на Rust в
`src/silero.rs`.

Всё собирается в `silero_voice.dll`. LoreLens сам с libtorch не связан: он загружает эту DLL из
папки голоса, только когда в настройках выбран Silero, и общается с ней через несколько C-функций
(`src/lib.rs`). Так программа остаётся одним exe, а 300 МБ библиотек нужны лишь тем, кто
пользуется этим голосом.

## Сборка из исходников

Нужны Rust и Visual Studio (компилятор C++).

1. Один раз превратить модель Silero в файлы, которые читаются без Python. Для этого шага нужен
   Python с PyTorch, и только на машине, где собирается голос:

   ```
   python export_silero.py v5_5_ru.pt model
   ```

   Модель: <https://models.silero.ai/models/tts/ru/v5_5_ru.pt>.

2. Собрать DLL и сложить всё в `package/`; с `-Install` ещё и скопировать в папку LoreLens:

   ```
   pwsh -File build.ps1 -Install
   ```

   Сборка сама скачивает libtorch (около 200 МБ) и крейт `torch-sys`, в который `vendor.ps1`
   вносит две правки: стандарт C++20 для Visual Studio (иначе заголовки libtorch 2.13 не
   собираются) и переименованный тип `module` (в C++20 строка не может начинаться с этого слова).

Архив для Releases: содержимое `package/` в zip.

### Проверка

`export_silero.py` сохраняет ещё и `model/reference.json`: что Python выдал для нескольких фраз.
Тест сверяет с ним Rust-версию. Ударения и длина звука должны совпасть в точности:

```
$env:PATH = "$PWD\package;$env:PATH"; $env:SILERO_DIR = "$PWD\model"; cargo test --release
```

## Что стоит знать

- Silero знает только русские буквы, остальное молча пропускает. Поэтому перед чтением числа
  пишутся словами, а латиница русскими буквами (`spell_out` в `src/silero.rs`). Это не часть
  Silero и сделано грубо: числа всегда в именительном падеже.
- Первые два чтения после загрузки модели медленные (libtorch настраивает сети на ходу), поэтому
  при загрузке модель читает две короткие фразы вхолостую.
